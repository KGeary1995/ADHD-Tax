# 15-minute phone test (Android)

A quick pass over the features that have only been checked in tests and web screenshots. Run it after installing a new build. Use made-up tasks only (no patient details). Do it in the regular (personal) copy of the app; the work-profile copy only needs step 1.

To report: reply with the step numbers that failed and a screenshot of each. "All pass" is a fine answer too.

**Before you start:** install the latest build from `…/android-latest/Gumption.apk` over the current app.

## 1. After the update (1 min)
1.1 The app opens and the name under the icon says **Gumption**.
1.2 Settings → Sync: Personal still shows as connected, with no "Reconnect". (Give it up to a minute; it retries by itself.) In the work-profile copy, Work is still connected.
1.3 Your tasks are still there.

## 2. Start the timer first, so it runs while you test (1 min)
2.1 Quick add (+) → type `Test timer` → **Add & start**.
2.2 On the focus screen, tap the people icon (**Hold me to it**). The share sheet opens with "I'm starting "Test timer" now, for 15 min…". Back out without sending.
2.3 Leave the focus screen running and press the home button. Carry on with step 3. **Step 9 checks the alert.**

## 3. Today (1 min)
3.1 The headline says **Don't decide. Just start.**
3.2 The card's top line is short, e.g. `15 min · due tomorrow`, with no clock time.
3.3 Tap the situation bar (`30 min / At home`): a sheet opens to change time, going out and energy. Change the time; the card re-picks.
3.4 **Not this one** shows a different task. **Later** hides it.

## 4. Quick add (2 min)
4.1 Tap +. You see the task box, **How long?**, Personal/Work and **More options**. No Priority yet.
4.2 Type `Call the bank tomorrow 2pm 15 min urgent`. Chips appear for tomorrow 2pm, 15m and Critical.
4.3 Tap **More options**: Priority, dread and **Leave the house** appear. Close it, reopen Quick add: it remembers.
4.4 Tap the mic and say "buy printer paper". It types it. (Allow the microphone if asked.)
4.5 Add it. It appears in Tasks.

## 5. Tasks (2 min)
5.1 At the top there's one button (**Everything**) and, if any, **Weekly reset**. No rows of pills.
5.2 Tap **Everything** → choose **Work** → **Done**. Only Work tasks show and the button says **Work**. Set it back to Everything.
5.3 In the same sheet, choose **Board**, then **Done**: the board shows. Switch back to **List**.
5.4 Rows show only the due date and length (e.g. `Due Oct 25 · 30 min`).
5.5 Swipe a test task right: it's marked done, with **Undo** at the bottom. Tap Undo.
5.6 Swipe a test task left: it's deleted, with **Undo**. Tap Undo.

## 6. A task's editor (1 min)
6.1 Open a task with no first step. Under **First 2-minute step** there are idea chips (e.g. for "Call the bank": *Find the number and put it on screen*). Tap one; it fills in.
6.2 Under Checklist, tap **Suggest steps**: a few steps appear. Save.

## 7. Share into the app (1 min)
7.1 In Chrome (or Messages), select some text → **Share** → **Gumption**.
7.2 Gumption opens with Quick add prefilled. There's only one copy of the app open (the Recents screen shows one Gumption).

## 8. Home-screen widget (2 min)
8.1 Long-press the home screen → Widgets → **Gumption**. Four sizes: start, square, card, card + next up. Add **card**.
8.2 It shows the same task as Today, with **Start**. Tap Start: the focus timer opens on that task.
8.3 Tap **+** on the widget: Quick add opens.

## 9. Timer alert (check when it's due)
9.1 About 15 minutes after step 2, a "time's up" notification arrives even with the app in the background or the screen off.
9.2 Tapping it opens the app.
If it's late or missing: Android Settings → Apps → Gumption → Battery → **Unrestricted**, then try a 5-minute timer (**5 min** on the Today card).

## 10. Evening and errands (2 min)
10.1 After 5 pm, Today shows **Wrap up** at the bottom. Tap it: today's done tasks show, you can pick tomorrow's first task, then **Done for today**. Tomorrow morning, Today should offer that task first.
10.2 In the editor, turn on **Need to leave the house** for two test tasks and give each a place (Pharmacy, Post office). On Today, set the situation to **Can go out** and 1h. An **Errand run** banner appears; tap it to see both stops.

## 11. Backup and guide (1 min)
11.1 Settings → Backup → **Save a backup file** → save it to Downloads. A confirmation appears.
11.2 **Restore from a backup file** → pick that file → it says how many tasks it has → **Restore** (leave "Also restore its settings" off). Nothing changes: a restore only adds back what's missing, and it's the same data.
11.3 Settings → Help → **How Gumption works**: it opens, and a **Go to…** button jumps to that screen.

## Clean up
Delete the test tasks (swipe left) and remove the widget if you don't want it.
